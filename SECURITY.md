# Security Policy

Dieses Repository paketiert cryptii als Lesezeichen-Hub-Modul. Sicherheitsrelevante Updates werden auf die jeweils aktuelle Modulversion angewendet.

## Reporting a Vulnerability

Bitte melde Sicherheitsprobleme nicht als oeffentliches Issue. Nutze stattdessen GitHub Security Advisories im Repository oder kontaktiere die Maintainer der Organisation `Lesezeichen-Hub`.
